# Payment Integration Study Project

A study project built to learn and practice integrating **Stripe Subscriptions** and **PayPal** into a web application.

## Project Purpose

The primary goal of this project is to understand how payment gateways work and how to integrate them into a web application.

As this is a learning project, the focus is on:

- **Payment Integration:** Implementing Stripe and PayPal payment systems.
- **Subscription Management:** Learning how to handle subscription-based payments using Stripe.
- **Payment Flow:** Understanding the payment process, including checkout and payment status handling.

The UI/UX design, branding, company concept, and overall business logic are secondary priorities. They exist mainly to support the implementation and testing of payment features.

**This project is built for learning purposes, with payment integration as its main focus.**
